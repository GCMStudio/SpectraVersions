## 📦 Purpose

This repository stores version information used by the Spectra ecosystem, including:

- Latest stable version
- Release history
- Changelogs
- Build metadata
- Update severity
- Minimum supported version

Applications such as the **Spectra Updater** use this repository to determine whether updates are available.
